# Foodie

## Overview

Foodie is a modern, responsive fast food website built with HTML, CSS, and JavaScript. It showcases a dynamic restaurant landing page with a hero section, menu highlights, shop and blog sections, interactive search, and mobile-friendly navigation.

## Features

- Responsive hero section with call-to-action and food visuals
- Mobile-friendly navigation menu with toggle support
- Interactive search overlay with open and close controls
- Food shop and promotional menu cards
- Sticky header and back-to-top behavior on scroll
- Smooth UI interactions using JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Ionicons

## Installation

1. Clone the repository.
2. Navigate to the project directory.
3. Open `Index.html` in a web browser.
4. View the application locally.

## Usage

Use the navigation links to explore the homepage, about section, food menu, and blog previews. Click the search icon to open the search overlay, and use the reservation button to simulate booking engagement. The responsive layout adapts across desktop and mobile screens.
